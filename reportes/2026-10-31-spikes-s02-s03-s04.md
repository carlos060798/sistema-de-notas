# Spikes S0.2, S0.3 y S0.4 (2026-10-31)

Código: `spikes/s02-formatos/spike.js`. Node 24.20; exceljs 4.4.0, pdfkit 0.20.2, docx 9.15.1.

| Spike | Prueba | Resultado |
|---|---|---|
| S0.2 | Exportar tres tablas a `.xlsx` y reconstruir una base vacía desde él | **Idéntico** (incluye un adjunto binario en base64), 301 ms |
| S0.3 | PDF con tildes, eñes y diéresis | `%PDF` válido, 1423 bytes |
| S0.3 | DOCX con tildes y eñes | archivo zip válido, 9528 bytes |
| S0.4 | `VACUUM INTO` produce una copia con el adjunto dentro | `integrity_check` = ok, adjunto de 8 bytes presente |
| S0.4 | Base con 200 bytes corrompidos | detectada: «database disk image is malformed» al abrir |

## Lo que NO se comprobó
- Que el PDF y el DOCX se vean bien visualmente (solo se validó el formato del archivo; falta abrirlos con Word y un lector de PDF).
- El tamaño del ejecutable con estas bibliotecas empaquetadas con `esbuild` (`node_modules` pesa 94 MB sin empaquetar).
- Volúmenes reales: pocas filas de prueba.
- Fórmulas de Excel: el respaldo guarda valores, no fórmulas.

## Conclusión
La pila del ADR-01 es viable para respaldo, recuperación y exportación. Pendiente la prueba visual de PDF y Word.
